## 📐 Mode A: Universal Mathematical & Physics Engine

### 1. Standard & Advanced Coordinate Systems
* **1D Functions & 2D Explicit Curves**: $y = f(x)$, damped oscillations $y = e^{-0.2x}\sin(3x)$, Gaussian probability densities $f(x) = \frac{1}{\sigma\sqrt{2\pi}}e^{-\frac{1}{2}(\frac{x-\mu}{\sigma})^2}$.
* **2D Implicit Algebraic Curves**: $x^2 + y^2 = 25$ (Circle), $x^3 + y^3 - 6xy = 0$ (Folium of Descartes), $(x^2+y^2)^2 = 2(x^2-y^2)$ (Lemniscate of Bernoulli).
* **2D Polar Coordinates**: $r = 4\sin(4\theta)$ (Rose curve), $r = 3(1 - \cos\theta)$ (Cardioid), $r = 0.5\theta$ (Archimedean spiral).
* **2D & 3D Parametric Curves**: $\mathbf{r}(t) = (\cos t, \sin t, 0.2t)$ (3D Space Helix), Torus Knots, Lissajous figures.
* **3D Explicit Surfaces**: $z = \sin(x)\cos(y)$ (Wave Ripple), $z = x^2 - y^2$ (Hyperbolic Paraboloid / Saddle), $z = \frac{\sin(\sqrt{x^2+y^2})}{\sqrt{x^2+y^2}}$ (Sombrero).
* **3D Implicit Isosurface Manifolds**: $x^2 + y^2 + z^2 = 25$ (Sphere), Torus manifolds, Gielis superformulas.
* **Vector Fields**: 2D & 3D vector gradient and curl fields $\mathbf{F}(x, y, z) = (u, v, w)$ with 3D streamlines and quiver arrows.
* **Multi-Equation Layer Overlay**: Superimpose multiple independent equations on the same coordinate space with automatic intersection solving and layer management.

### 2. ⚛️ Quantum Physics: Hydrogen Electron Orbitals ($|\psi_{n,l,m}|^2$)
* **Exact Analytical Wavefunctions**: Solves the 3D Schrödinger equation using Generalized Laguerre polynomials ($L_{n-l-1}^{2l+1}$) and Spherical Harmonics ($Y_l^m$).
* **Marching Cubes 3D Isosurfaces**: Computes probability density isosurfaces with phase color-mapping for quantum states:
  * **$1s$** Ground State ($n=1, l=0, m=0$)
  * **$2p_z$** Dumbbell ($n=2, l=1, m=0$)
  * **$3d_{z^2}$** Torus ($n=3, l=2, m=0$)
  * **$3d_{xy}$** Cloverleaf ($n=3, l=2, m=2$)
  * **$4f$** Complex orbital states ($n=4, l=3, m=0 \dots 3$)
* Real-time iso-percentile slider ($50\% - 99\%$) and nucleus marker.

### 3. 🌀 Fractals & Complex Dynamics (Mandelbrot & Julia Sets)
* **Non-Linear Iterative Dynamics**: $z_{n+1} = z_n^2 + c$.
* **Mandelbrot Set**: Real-time zoom factor up to $10,000\times$, divergence threshold, and iteration controls ($20 - 300$).
* **Julia Set**: Customizable complex seeds ($c = a + bi$) with famous presets: *Douady Rabbit, Dendrite Tree, San Marco Dragon, Electric Spiral*.
* **3D Escape-Time Heightfield**: Visualizes iteration divergence as a 3D surface manifold.

### 4. 🪐 Astrophysics: Gravitational N-Body Simulator
* **Real-time Newtonian Mechanics**: Numerical integration (Runge-Kutta 4 / Velocity Verlet) of $N$ interacting masses:
  $$\mathbf{F}_i = \sum_{j \ne i} \frac{G m_i m_j (\mathbf{r}_j - \mathbf{r}_i)}{(\|\mathbf{r}_j - \mathbf{r}_i\|^2 + \epsilon^2)^{3/2}}$$
* **Celestial Presets**:
  * *Chaotic Three-Body Problem (Figure-8 Choreography)*
  * *Inner Solar System (Sun, Mercury, Venus, Earth, Mars, Jupiter)*
  * *Binary Star System with Orbiting Exoplanet*
* Adjustable gravitational constant $G$, integration step $dt$, and real-time celestial trajectory trails.

### 5. 🧬 Deep Neural Network & DNA Double-Helix Studio
* **Deep Neural Network 3D Architecture Visualizer**: Interactive 3D graph of multi-layer neural networks (MLPs, Transformers) with synaptic weight edges ($W_{ij}$), customizable layer sizes (e.g. `[4, 8, 8, 3]`), and activation node markers.
* **DNA Macromolecule Double-Helix**: 3D parametric sugar-phosphate backbones ($5' \rightarrow 3'$ and $3' \rightarrow 5'$) with hydrogen-bonded base pairs (Adenine-Thymine and Guanine-Cytosine).

### 6. 🧊 4D Tesseract Hypercube ($SO(4)$ Projection)
* Full 4D hypercube geometry consisting of 16 vertices, 32 edges, and 24 square faces.
* **$SO(4)$ 6D Rotational Matrices**: Real-time 60 FPS rotation across 6 distinct planes: $XY, XZ, XW, YZ, YW, ZW$.
* Perspective 4D-to-3D projection with 3D Plotly rendering.

### 7. 🌪️ Non-Linear Chaotic Attractors (Lorenz, Rössler, Aizawa)
* **Lorenz Attractor**: $\frac{dx}{dt} = \sigma(y - x), \frac{dy}{dt} = x(\rho - z) - y, \frac{dz}{dt} = xy - \beta z$.
* **Rössler Attractor**: Continuous-time dynamical system with chaotic spiral bands.
* **Aizawa Attractor**: 3D spherical chaotic attractor with twin rotating vortex tubes.
* Integrated using adaptive Runge-Kutta 4th-order (RK4) integration with 4,000+ points and gradient speed coloring.

### 8. 🎨 Complex Analysis & Riemann Surfaces (HSV Domain Coloring)
* Visualizes complex-valued functions $w = f(z)$ for $z \in \mathbb{C}$.
* **3D Riemann Surface**: Height $Z = |f(z)|$ (modulus / magnitude) with surface color mapped to $\arg(f(z))$ (complex phase angle in $[-\pi, \pi]$).
* Presets: $f(z) = z^2 - 1$, $f(z) = \frac{1}{z}$, $f(z) = e^z$, $f(z) = \sin(z)$, $f(z) = z^3 - 1$.

### 9. 📐 Calculus & Differential Geometry Suite
* **Tangent Lines & Osculating Planes**: Instant tangent line at user-selected $x_0$.
* **Normals & Tangent Planes for 3D Surfaces**: Analytical normal vectors $\mathbf{n} = \nabla F$.
* **Definite & Indefinite Integrals**: Automatic symbolic antiderivative $\int f(x) dx$.
* **Riemann Sum Approximations**: Left, Right, and Midpoint Riemann sum rectangles overlaid on the curve.
* **Audio Sonification**: Web Audio API oscillator synthesizing mathematical frequencies from curve heights!

### 10. 🎙️ AI Voice Math Audio Tutor & Step-by-Step Derivations
* **Spoken Audio Commentary**: Uses the Web Speech Synthesis API to verbally explain critical stationary points, roots, curvature, asymptotic limits, and physical meaning out loud.
* **Full Step-by-Step Symbolic Calculus**: Displays analytical first derivatives ($f'(x)$), second derivatives ($f''(x)$), indefinite integrals ($\int f(x) dx$), critical extrema roots, and 4th-order Taylor polynomial expansions in formatted LaTeX.

### 11. 🎮 Inverse Graphing Game ("Guess the Equation")
* **Interactive Mathematical Puzzle**: The engine displays a target curve on the canvas; you formulate the algebraic equation to match it.
* Instant **Mean Absolute Error (MAE)** and **Accuracy Score (0–100%)**.
* Confetti animations upon passing levels ($\ge 88\%$ accuracy).
* 4 progressive tiers: *Linear Shifts $\rightarrow$ Parabolic Trajectories $\rightarrow$ Trigonometric Waves $\rightarrow$ Damped Wave Packets*.

## 🎙️ Multimodal Input Studios

Graphxyz supports 6 distinct input modalities:
1. **Plain Math Natural Syntax**: Write `sin(x)*cos(y)` or `[e^(-0.5*((x-u)/s)^2)] / (s*sqrt(2*pi))`.
2. **LaTeX Equation Editor**: Full KaTeX live preview with auto-sanitization.
3. **Visual Blocks Builder**: Clickable palette for trigonometric, power, exponential, logarithmic, and calculus operators.
4. **AI Copilot Natural Language Prompt**: Type *"Draw a 3D saddle that looks like a Pringle chip"* $\rightarrow$ AI infers $z = \frac{x^2}{4} - \frac{y^2}{4}$.
5. **🎙️ Voice-to-Math Dictation**: Speak mathematical formulas naturally using the Web Speech Recognition API.
6. **📷 Image / Screenshot Math OCR Scanner**: Drag-and-drop or paste photos of whiteboard equations to auto-parse and plot them.

## 🚀 Quick Start & Local Development

### Prerequisites
* **Python 3.10+**
* **Node.js 18+** (Node.js 20+ recommended)

### 1. Clone the Repository
```bash
git clone https://github.com/OVSSVARUN-2007/graphxyz.git
cd graphxyz
```

### 2. Backend Setup
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r backend/requirements.txt
```

### 3. Frontend Setup
```bash
cd frontend
npm install
npm run build
cd ..
```

### 4. Run the Application
```bash
python3 -m uvicorn main:app --app-dir backend --host 127.0.0.1 --port 8000 --reload
```

Open your browser at **`http://localhost:8000`**!

## 📡 Complete REST API Documentation

### 1. Math Evaluation Endpoints

#### `POST /api/math/evaluate`
Evaluates explicit, implicit, parametric, or polar equations.
```json
{
  "equation": "z = \\sin(x)\\cos(y)",
  "dimension_override": "3D",
  "resolution": 200,
  "domain_ranges": {
    "x": [-6.28, 6.28],
    "y": [-6.28, 6.28]
  }
}
```

#### `POST /api/math/quantum-orbital`
Generates 3D hydrogen electron wavefunction probability isosurfaces.
```json
{
  "n": 3,
  "l": 2,
  "m": 0,
  "grid_res": 35,
  "box_size": 16.0,
  "isopercentile": 90.0
}
```

#### `POST /api/math/fractal`
Calculates Mandelbrot or Julia escape-time heightfields.
```json
{
  "fractal_type": "julia",
  "zoom": 1.0,
  "max_iter": 100,
  "julia_c": [-0.7, 0.27015],
  "res": 100
}
```

#### `POST /api/math/nbody`
Simulates 3D gravitational multi-body celestial dynamics.
```json
{
  "preset": "three_body",
  "num_steps": 600,
  "dt": 0.015,
  "G": 1.0
}
```

#### `POST /api/math/neural-dna`
Renders 3D Deep Neural Network architectures or DNA double-helix structures.
```json
{
  "model_type": "neural_net",
  "layers": [4, 8, 8, 3]
}
```

#### `POST /api/math/step-by-step`
Calculates analytical derivatives, integrals, roots, and speech tutor scripts.
```json
{
  "equation": "x^3 - 3*x + 1"
}
```

### 2. Deep Learning NLP Endpoints

#### `POST /api/nlp/analyze`
Computes sentence embeddings, PCA/t-SNE/UMAP projections, sentiment arcs, and topic distributions.
```json
{
  "text": "Artificial intelligence and neural networks are transforming science.",
  "method": "PCA",
  "dimension_override": "3D"
}
```

#### `POST /api/nlp/compare`
Side-by-side comparative analysis of two texts.
```json
{
  "text1": "AI improves scientific discovery and productivity.",
  "text2": "Unregulated AI creates existential risks and algorithmic bias.",
  "method": "PCA"
}
```

### 3. Sharing & Snapshot Endpoints

#### `POST /api/share/snapshot`
Uploads base64 graph image snapshot and returns a public preview token.
```json
{
  "image_base64": "data:image/png;base64,iVBORw0KGgo..."
}
```

#### `GET /api/share/snapshot/{token}.png`
Serves the rendered PNG image directly for social media link unfurls.
